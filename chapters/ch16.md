# 第十六章 拜功种类续 · 会礼与特殊拜 · 殡礼（第二册 p1-166）

> 源：第二册 p1-166（续第十篇拜功的种类：旅行者减礼/并礼 → 两会礼 → 日食月食拜 → 求雨拜 → 警惕拜 → 殡礼及亡人后事全流程）。
> 本篇跨越极多主题，按子主题速查如下。

## Ⅰ 旅行者的拜功

- **减礼（قصر）**：旅行者可把四拜主命（晌/晡/宵）减为两拜（「减礼」）；晨礼与昏礼不减法（两拜/三拜定式不变）。
- 允许减礼之行程：约「两站/一昼夜路程（约 80 公里上下）」——原文按当时里程表，各派有说；哈派众说「可行三日路」之争见原文。
- **并礼（جمع）**：条件为①旅途②大雨③黑暗泥泞④病重⑤昏晕/失力⑥（受戒准哈吉于阿拉法特/穆兹代里发）——前五类「许可」，⑥类「圣行」。
  - 提前并礼（未入时先礼）：须确知途中无礼拜条件、行程紧张等两项前提（原文两条）。
- 旅行者减/并之细则：制定依据（古兰「你们旅行时无妨减短礼拜」）、居家者领拜时旅行者跟随全礼、旅途中圣行拜之议等——原文有详。

## Ⅱ 两会礼（开斋节/宰牲节大礼）

- **定性三主张**：社会主命（罕）／当然（部分）／强调圣行（哈/沙）。
- **时间**：日出升高一枪杆至日偏前（晌时入前）。
- **地点**：郊外旷野为最宜（先知惯于郊外），城中清真寺亦可。
- **礼法**：两拜；拜内增数个「大赞词」（哈派每拜三增——「真主至大」抬手；头拜读经后等，原文逐项）；明念《古兰》（罕派「明念开头章和苏勒」据欧麦尔君臣传述）。
- **会礼宣讲（呼图白）**：马派「可嘉」；沙/哈/罕视「拜后劝戒宣讲」为要素级（沙派列条件）；宣讲在拜后（主麻则在拜前）。
- **大赞词（تکبیر）**：会礼日晨前往时念；开斋节期间主命拜后连念（限定日数各派有差）。
- **会礼前后**：哈/马/罕憎恶郊外会礼前后礼副功；沙派许（日出后、除伊玛目领拜场合）。
- **可嘉**：十日（祖勒·哈杰前十日）多干善功、沐浴更衣（不擦香水）、走亲访友互贺。

## Ⅲ 日食、月食拜

- **定性**：强调的圣行（四派一致）。
- **礼法分歧**：
  - 哈派：两拜、每拜一鞠躬两叩头、不宣讲不宣礼（如副功）；
  - 沙/马/罕：每拜两鞠躬两叩头（共两拜四躬四叩——圣妻阿依莎传述「两拜中鞠躬四次叩四次头」）；沙派拜中明念。
- 日食拜与主命时间撞车：恐失时则先主命（沙/罕主张）；时间宽裕先日食拜。
- 赶拜/遗漏：追补至伊玛目鞠躬（同集礼原则）。

## Ⅳ 求雨拜（استسقاء）

- **定义**：干旱缺水时以礼拜+宣讲+求饶+赞主祈雨。
- **定性**：艾卜·哈尼法主张「个人副功」（非集礼圣行）；其余教法家主张「城郊集礼两拜」。
- **方式**：郊外两拜→宣讲；衣冠朴素、谦卑哀愁（圣训「谦逊地、衣褴褛地、恭顺地、哀愁地出去求雨，像两会礼那样礼两拜」）。
- **十件可嘉**：悔过、济贫、劝善、弃亏心、多做义举等。

## Ⅴ 警惕拜（战争拜，صلاة الخوف）

- **定性**：圣行（《古兰》妇女章102节+圣行）。
- **两种礼法**：①队伍分两组、先后随两位伊玛目；②极端紧急时骑乘/步行就位，以示意鞠躬叩头、不苛朝向。
- 拜中走动、作战所需动作（冲杀/反击）不坏拜；非战之多动才坏。
- 赶拜者：同集礼规则；（哈派细节：昏礼只赶上一拜者补法见原文）。

## Ⅵ 殡礼与亡人后事（全流程）

- **责任顺序**：洗遗体 → 包卡方 → 殡礼 → 埋葬（为「社会主命」，众有则脱责）。
- **临终护理**：提示「清真言」（万物非主唯有真主）；面朝正向；念「雅辛章」（哈部分后贤+沙派又加「雷霆章」说）；靠向亲人；逐项圣行。
- **报丧/速葬**：罕派憎恶张扬报丧（侯宰法嘱托）；速葬为可嘉（防腐败、免耽延）。
- **洗遗体**：社会主命；殉道者**不洗**（连带之「附属殉道者」如难产、水淹、火焚、疫病、倒塌、为主道等亡故者则要洗）。
- **卡方**：男子禁丝绸/金线布（罕派女子亦禁）；妇女可用丝绸（其余三派）；件数式样按派（三件男/五件女为要目，原文详）。
- **殡礼**：
  - 程序：站礼、四「大赞词」（一称颂、二赞圣、三为亡人祈祷、四出赛俩目）——要素至少「大赞词+站礼」；
  - 伊玛目位置：对亡人（男对头/女对中）——原文对比；
  - 赶拜者：赶上几个大赞词念几个，未赶上不补（圣妻阿依莎传述「你听到的念，未听到的不用补」）；
  - 缺席殡礼（不在场之亡人）可行（为南扎氏缺席殡礼-“两个圣训集”）；埋葬后仍可殡礼（罕派主张刨坟抬出补礼，见原文）；
  - 胎儿/婴儿：满四个月小产胎儿须洗+殡礼（罕）；无生命特征者憎恶殡礼、可嘉洗净包布葬。
  - 憎恶时辰：日出、日中、日落、晨礼后/晡礼后（哈派严重憎恶；沙派二十四时皆可）。
- **送殡/埋葬**：送殡为可嘉善功（妇女除近亲外不送）；坟坑规格（侧穴/直槽两式）；抬亡人以「快走不跑」；下葬念词；坟头立石作记；游坟（探墓）为圣行、可念经祈饶（后贤主张可转回赐）；禁坐坟/禁书写陵墓（防偶像化）。
- **安慰丧主**：三日内为宜；哭泣许、嚎哭禁（断发/撕衣等愚昧行径禁）；忍耐有厚报；近邻为丧主讲食（可嘉）；为逝者念经祈饶并转回赐（马/沙先贤主张无益、后贤主流主张有益）。
