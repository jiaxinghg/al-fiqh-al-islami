# 第十八章 天课（第二册 · 第四门，p262-345）

> 源：第二册 p262-345。核心关切：**天课定义、五种课税财产、满贯（尼萨卜）与税率、开斋捐、自愿施舍**。

## Ⅰ 天课总则

- **定义**：富人每年从财产中拿出 1/40（2.5%）用于救济《古兰》所列**八种人**：穷人、可怜人、（天课）管理者、心被团结者、无力赎身者、无力还债者、为主道工作者、途中困乏者（忏悔章60节）。
- **法定地位**：五大功修之一；「天课」词义=发展/洁净（「栽科台」）。
- **立判时间**：斋戒定制后、开斋捐定制后才定天课（624 年前后麦地那）。拒缴者受两世刑罚；**否认其为主命**者按叛教论（令悔过三回）；「不知者不断其悖信」。
- 财产损失：到课期前故意挥霍逃课 → 仍当然；灾损部分 → 免该部分。

## Ⅱ 课税财产（五种）

1. **金、银（及纸币）**：金满贯 = 20 钱（约百克上下，原文按「14 里拉」折算）；银满贯 = 200 迪尔汗；税率 2.5%（1/40）；满一年为条件。金银首饰：哈/马派男女首饰均课（男子戴金饰非法）；首饰是否纳入满贯各派有差。
2. **矿藏（金矿银矿）**：开采即课，不以年计（同庄稼例）；罕派另加条件（原文）；海底珊瑚/珍珠/鱼不课。
3. **经商货物**：货价达满贯+满一年+为买卖而持有 → 课；本钱 + 利润并入；房产用于买卖者课、自住/出租居所与工具器械不课（哈派细则）。
4. **庄稼与水果（地课）**：
   - 雨水/河水自然灌溉 → 1/10；人工灌溉/汲水 → 1/20；
   - 哈派：凡田产所出无最低额（无论多寡皆课）；沙/罕/马以满贯限（五牲畜优素可等）；
   - 收获日即课、可折现缴（哈）／实物缴（沙/罕/马）；
   - 公司/公有地/租地所出课责归属原文逐条。
5. **牲畜（牛/羊/驼）**：满贯分级（5 驼=1 羊等，原文表）；牧放+全年放牧才课；马：哈大伊玛目主张课、两弟子不课（以弟子为依）。

- 债务/被动财富：哈派债分三类（直缴/缓缴/难缴）各定课法；纸币按金银价折算定满贯。

## Ⅲ 天课的应用

- 八种人必达；不可发给八种之外；富人/哈申后裔/近亲应养者不受天课。
- 发放受贿者之条件/「心被团结者」当代适用性分歧（原文）——引用必带学派。
- 发放方式：可亲手（古兰「在他们的财产中有乞讨者与穷人的份额」）或交管理赈务者。
- 折现缴：哈派可折市价货币；沙/罕/马主张实物对应。
- 领取者条件（五条件）与「把天课给错了人」补救（原文）。
- 当地有需优先当地发放；可代亡人缴欠课（从遗产出三分之一）。

## Ⅳ 开斋捐（زكاة الفطر）

- 定性：对富余者（有满贯/自足）为**当然**；开斋节前施。
- 时间：哈派「开斋日黎明后、会礼前」；沙/罕/马「开斋节前夜日落即当然」（可提前至入斋月后——各派）。
- 数量物：一「萨阿」（约 2.2-3 公斤）小麦/大枣/葡萄干等主食；哈派可折现金（其余三派实物）。
- 分配：同天课八种人。

## Ⅴ 自愿施舍（صدقة）

- **地位**：圣行，任何时候可嘉；秘密施胜过公开（天课可公开以示范）。
- 散尽家财：孤身無負擔者「可嘉」；有家人赡养义务者须留基本生活（「在满足自己与家眷基本生活后施舍才可嘉」——两部圣训集）。
- 注意事项：量力（「半个枣子也防火狱」）、先济近亲/欠债者/贫而廉者、举意回赐归全体穆斯林（可嘉）、禁以非法财施舍（不蒙悦纳）、禁数恩/禁高人一等/禁劣品充数。

## 引文示例

- 「你从他们的财产中征收赈款，借以洁净他们」（忏悔章103节）——天课立法总纲。

## 使用提示

- 判定「××要出天课吗」：五种财产对号 → 查满贯 → 查满年 → 定税率（2.5%/10%/20%）→ 交付八种人；
- 「开斋捐」独立于天课满贯（自足者即当然）；
- 与第二册 ch17（斋戒）接壤：开斋捐在开斋节前施，与费迪耶勿混。
