# 第二十一章 发誓（续）· 许愿 · 罚赎（第三册 p1-66）

> 源：第三册 p1-66（第六门续）。本章收束「发誓」篇（发誓者/被发誓者条件、要素），并承「许愿（奈兹尔）」与**罚赎（卡法拉）总论**——罚赎也是 ch17/19/20 反复引用的共同机制。

## Ⅰ 发誓（续）

- **发誓者条件**：成年、理智（儿童/疯子发誓无效）；被迫者誓无效（但主动顺北律者自担）。
- **被发誓者（目标事）条件**：须为将来可成之事；本体不存在/不可能之事（如河水倒流）誓不成立——艾卜·尤素甫派以「事发生时生效」论。
- **要素**：以真主名义（尊名/属性）为誓；「若…」等条件句使誓暂缓/不生（原文论犹豫誓）。
- **场景研习（两学生之分歧）**：
  - 有人发誓「我不出寺门」，后随伊玛目入拜并从寺中出拜（艾卜·哈尼法/艾卜·尤素甫：未违誓——拜内既定动作不被视为「出寺」；穆罕默德：违誓——因拜毕而回）；
  - 跟着伊玛目礼拜且伊玛目开赛俩目（出门与否各派解析入原文）。
- 违誓成立 → 执行罚赎（本章Ⅲ）。

## Ⅱ 许愿（النذر）

- **定义**：对真主承诺「为接近真主而做某善功」——承诺之事若为自己应尽义务（五番拜/斋月斋等）则许愿无效（本就当然而不二赘）。
- **许愿者条件**：理智成年穆斯林（非穆斯林/疯者愿无效）；自由非必要条件（未获释者许愿亦有效）。
- **被许（事）条件（三）**：①为善功（不可许饮酒/断亲等罪案）；②取悦真主（不可许生活方式类如「我永远不吃早餐」）；③真主可承（「违主之事上无愿」——布哈里圣训）；须有自主支配权的财产方可许「施舍××」。
- **许愿的教法定性**：哈派「服从真主之事中并愿当育许愿」——履行**应当**（当然）；沙/罕同主「当场尤其当履行」；部分马派憎恶（若其属禁/犯罪则禁立）。
- 愤怒中许愿（「指主发誓若我儿子……我必不与他说话」）→ 按做事/违誓双轨：好事则行、坏事罚赎（「以许愿泄愤，其罚赎如发誓」——辑录转述）。
- 许愿之模糊/未定期限（如「我要为真主斋戒一月」未言哪月）：尽快完成；危难中许愿（达目的才斋）——达则必行（多数派）；许愿之肉/物不可自肥（归穷人）。

## Ⅲ 罚赎（الكفارة）——四主情形

本库全书罚赎共枢：**供食 / 供衣 / 释奴 / 斋戒**四层依能力递降。

1. **将妻比母（زِهار）罚赎**：供十贫民中等伙食 / 供衣 / 释奴一名——古兰明文；无此三者则连续斋戒二月（妇女）；再无能则……
2. **故意坏莱麦丹斋（夫妇相聚/食饮，哈/马以比母例）罚赎**：同齋层（供食/释奴/连斋两月）。
3. **误杀之罚赎**（沙、罕及马以故意类比）：释穆民奴隶/连斋两月/供食六十贫民。
4. **违誓之罚赎**（较前三为轻档）：
   - 第一层「供十贫民中等食物」或「供衣」或「释奴」（《古兰》筵席章89「或」三选一）；
   - 无力 → 连续斋戒三日（女性同）；
   - 违誓被抓又复犯 → 重罚赎（原文）。
- **供食细则**：一贫民一日中等份量（约莫德口粮）；不可给富人/非穆斯林近亲/奴隶（哈派允其顺民奴隶）；须「完全交付使贫民自由支配」，可折价。
- **释奴条件**：哈派释任何无主健康奴；沙/罕/马释穆民奴（「释一个信道的奴隶」）。
- **连斋细则**：连续不辍（断则重来）；无法分三日（只限违誓档）。

## 引文示例

- 「真主不以无意的誓处罚你们，而以有意的誓处罚你们；其罚赎是供十贫民中等食物……」——筵席章89，罚赎总纲。
- 「在违背主命的事上没有许愿」——许愿边界圣训。

## 使用提示

- 罚赎判定三连问：①犯的是「比母/坏斋/误杀/违誓」哪类？②「供食/供衣/释奴/连斋」能力到哪层？③执行细节（食物交付/奴隶身份/连斋续断）按章细目；
- 许愿查询：要件三连（善功/悦主/可承）→ 无效情形快速排除。
