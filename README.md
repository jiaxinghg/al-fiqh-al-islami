## 内容范围与忠实性

- **来源**：仅以三册中文汉译本（全文 OCR 验证通过）为素材；阿拉伯语原版 1~8 卷（纯扫描件）未纳入。
- **原则**：不编造、不整段照抄原文、每条要点 ≤2 短句；所有断法均可回溯原文页码。
- **学派对比**：原文以四派并举为标志性特色，本库保留全部分歧对照及派别归属。
